================================================================================
                        COMMON ERRORS & FIXES
================================================================================

Error: "Length must be between 1 and 256"
  → Cause: API key empty or too short
  → Fix: Get valid 64-char key from /apikey

Error: "Unauthorized"
  → Cause: API key wrong or expired
  → Fix: Regenerate at /apikey

Error: "Connection refused"
  → Cause: OpenAlgo not running
  → Fix: Start OpenAlgo, verify port 5000

Error: Environment variable not set
  → Cause: Variable not in shell
  → Fix: Set before running: export OPENALGO_API_KEY=...

Error: API key too short
  → Cause: Key is < 64 characters
  → Fix: Must be exactly 64 characters
