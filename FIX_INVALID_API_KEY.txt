================================================================================
                    COMMON ISSUES
================================================================================

ISSUE 1: "Cannot find API Key page"
  SOLUTION:
    1. Make sure you're logged in
    2. Look for Settings menu (top-right)
    3. Or go to: http://127.0.0.1:5000/apikey

ISSUE 2: "API Key page shows nothing"
  SOLUTION:
    1. Log out and log back in
    2. Refresh the page
    3. Try incognito/private browser window

ISSUE 3: "Still getting 'Invalid apikey' error"
  SOLUTION:
    1. Check you copied ENTIRE 64-character key
    2. Check no extra spaces in .env
    3. Regenerate new API key from dashboard
    4. Verify .env file is saved

ISSUE 4: "OpenAlgo is not running"
  SOLUTION:
    1. Start OpenAlgo: python app.py
    2. Wait for "Running on http://127.0.0.1:5000"
    3. Then access API key page
