    python nifty50_ema9_ema21_itm3_openalgo.py

    python nifty50_ema9_ema21_itm3_openalgo.py

OPTION 2: USE .env FILE (RECOMMENDED FOR DEVELOPMENT)

  1. Create a .env file in the same directory as the script:
     
     File: .env
     Content:
       OPENALGO_API_KEY=your-actual-api-key
       HOST_SERVER=http://127.0.0.1:5000
       LOTS=1
       ALLOW_LIVE_TRADING=false

  2. Install python-dotenv:
     pip install python-dotenv

  3. Add this to the script (after imports, before API_KEY line):
     
     from dotenv import load_dotenv
     load_dotenv()

  4. Run the script:
     python nifty50_ema9_ema21_itm3_openalgo.py

OPTION 3: MODIFY SCRIPT TO LOAD FROM .env (ALTERNATIVE)

  Edit the script and add after line 73:

================================================================================
TROUBLESHOOTING
================================================================================

ERROR: RuntimeError: OPENALGO_API_KEY is not set
SOLUTION:
  1. Check if API key is set: echo $OPENALGO_API_KEY
  2. If empty, set it: export OPENALGO_API_KEY="your-api-key"
  3. Run the script again

ERROR: Connection refused to http://127.0.0.1:5000
SOLUTION:
  1. Verify OpenAlgo server is running
  2. Check HOST_SERVER environment variable
  3. Verify port 5000 is accessible

ERROR: Invalid API key
SOLUTION:
  1. Verify API key is correct
  2. Check for extra spaces: echo $OPENALGO_API_KEY
  3. Copy API key again from OpenAlgo dashboard
  4. Set it again: export OPENALGO_API_KEY="new-api-key"

ERROR: Permission denied
SOLUTION:
  1. Check file permissions
  2. Run with proper permissions
  3. Check if script is executable
